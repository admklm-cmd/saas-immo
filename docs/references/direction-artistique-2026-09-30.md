# Règle globale de direction artistique — 30/09/2026

Source : demande de l'utilisateur (propriétaire produit), reproduite telle quelle.
Le `web-designer` la traduit en tokens et en spécifications dans `docs/design-system.md`.
Précision de l'utilisateur : plus aucun rouge, uniquement de l'orange — et l'orange ne sert pas
qu'aux erreurs ; ses usages exacts sont à définir par le `web-designer` avec l'utilisateur.

---

Le site est maintenant presque au bon niveau de finition.
Ne pas refaire le design.
Ajouter uniquement un langage visuel plus riche et plus intentionnel.

## 1. Couleurs

- ORANGE = attention / action requise / retard / blocage.
- BLEU = finition / détail / interaction / focus / mouvement.
- NOIR = information principale.
- GRIS = information secondaire.
- BLANC = respiration.

Ne pas utiliser de rouge.

Le bleu ne doit PAS devenir la couleur dominante. Il apparaît sous forme de : petits traits ;
repères ; points ; détails d'icônes ; contours fins ; indicateurs ; progressions ; micro-interactions.

L'orange doit être plus rare et réservé aux choses qui demandent une attention particulière.

## 2. Titres

Les titres principaux restent noirs et très forts.

Ajouter un petit langage d'accent autour d'eux : eyebrow / petit label ; petit repère bleu ;
trait ; détail graphique ; éventuellement un seul mot accentué.

Ne pas colorer les gros titres entièrement.

Référence : information principale très nette + petits accents qui structurent et donnent du rythme.

## 3. Particules / réseau vivant

Le réseau vivant devient une couche globale du SaaS, présent derrière TOUT le produit — pas
uniquement dans une section, sur un côté ou dans le coin supérieur droit. Il occupe toute la
surface disponible et reste visible : dans les marges ; entre les blocs ; autour des cartes ; dans
les espaces vides ; derrière certaines zones de contenu. Mais il reste toujours derrière l'interface.

Direction : blanc + gris + quelques signaux bleus. 3 plans de profondeur. Nœuds visibles.
Connexions visibles. Quelques chemins principaux. Impulsions bleues lentes et discrètes.
Aucun néon. Aucune esthétique cyberpunk. Aucun glow excessif.
Le réseau doit réellement participer à la composition.

## 4. Hiérarchie d'attention

Un utilisateur comprend instantanément où regarder :

Titre noir → petit accent bleu → élément important → orange uniquement si une action / anomalie
existe → reste de l'interface en gris / noir.

## 5. Critère de fin

Le site ne doit plus sembler fade. Il doit donner l'impression d'avoir beaucoup de détails, mais
ces détails doivent être intentionnels.

Si tout est de la même couleur, même poids, même taille, même animation : la section n'est pas
terminée. Si tout est coloré : la section n'est pas terminée non plus.

La bonne réponse se situe entre les deux : UNE HIÉRARCHIE VISUELLE TRÈS PRÉCISE.
